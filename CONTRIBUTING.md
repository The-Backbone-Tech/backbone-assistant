# Contributing

Read [AGENTS.md](AGENTS.md), the affected contract and [development guide](docs/development-map.md). Submit a coherent user outcome with focused tests, typechecks and regenerated artifacts. The integrated candidate must pass `pnpm check`.

## Sign your work (DCO)

Contributions use the [Developer Certificate of Origin](https://developercertificate.org/). `git commit -s` records that you wrote the change or have the right to submit it under Apache-2.0:

```text
Signed-off-by: Your Name <you@example.com>
```

Add a final `Agent:` trailer naming the model, or `Agent: human`. Enable the commit hook with `git config core.hooksPath scripts/hooks`.

The project owner is **The Backbone Tech**. [NOTICE](NOTICE) preserves project and upstream attribution independently of earlier private development history. Preserve those notices when redistributing.
