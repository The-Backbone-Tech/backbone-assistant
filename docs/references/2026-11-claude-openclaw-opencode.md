## What an open platform should take

The following are Backbone design recommendations. Licence consequences describe the inspected repository grants and documented integration boundaries, not a claim that every dependency or service shares that licence. Each decision points back to the evidence used.
- 1. Parallel work — **adapt**: Use script-owned orchestration with separate session contexts and explicit child permissions; reproduce Claude workflow behavior independently or adapt MIT OpenCode/OpenClaw code with retained notices. [design](https://code.claude.com/docs/en/workflows.md); [MIT](https://raw.githubusercontent.com/anomalyco/opencode/dev/LICENSE); [MIT](https://raw.githubusercontent.com/openclaw/openclaw/d7f88abfaacfab0cecdf064c98853bf6be3ea3b1/LICENSE); read 2026-11-09

- 3.
