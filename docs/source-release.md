# Source release 0.2.0

This is the first public clean-source release, prepared 14 November 2026. Private operational history, transcripts, account records and build output are excluded. The initial public commit starts a new history; it has no private parent commits. The version identifies the source generation, not a signed binary certification.

## Provenance and checks

The export uses the product's committed public-tree exporter and reviewed public variants from upstream qualified candidate `b1a152ff70fa00786a5ea080722fb25b3a0c9b86`. That candidate's gate passed package suites, pnpm check, 326 app end-to-end cases and 51 installed-app cases. The oracle reported 271 passed, zero failed and two explicitly unimplemented families. These are upstream source/installed observations; the cleaned public export is checked separately and does not inherit a claim that its own binary was built or installed.

Publication overlays correct public version/Team/LGPL status, repair the sharing guide’s engine-selection instructions, remove an obsolete private decision pointer and make hosted workflows manually dispatched. They change no runtime implementation or executable tests. Exported module digests are recomputed with the product algorithm. The public source tree is scanned for defined credential/identity/path patterns, reviewed for private records and checked with the native public-tree and structural tools. Its PNG assets contain product/demo artwork; the only workbook contains synthetic Quarter/Revenue values. These checks do not prove the absence of every possible secret format or arbitrary binary issue.

## Qualification limits

- Personal and Team are implemented; agent real-work use and installed sharing tests were on one Mac.
- Two installed app instances on that Mac are not two physical computers. Real two-computer and network-deployment acceptance remain open.
- Human acceptance and the complete Company configuration remain open.
- Mac builds are unsigned and unnotarised. No private-built disk image, CLI tarball or other binary is attached to this source release.
- GNU library provenance/rebuild and public-payload checks are implemented. Every future public binary must independently pass the native-source, notice, privacy and build checks.

Build from this clean checkout using the guides. A local source build is not automatically a public-distribution build; [ADR 0005](adr/0005-lgpl-native-libraries.md) and [install/build instructions](how-to/install-and-open-the-app.md) state the difference. The public repository is https://github.com/The-Backbone-Tech/backbone-assistant . Hosted workflows are manual; this publication does not start hosted qualification or change any private repository.
